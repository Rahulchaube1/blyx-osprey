# Osprey starter

Score a detection against a reference after clipping both to the camera frame.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Osprey** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
0.5
1
4
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/osprey) · [View the release](https://github.com/Rahulchaube1/blyx-osprey/releases/tag/v0.1.0)
